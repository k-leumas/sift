Make the owner-facing edges of the rules file work: `sift config check` reports every rules.yaml problem (D-05), `sift mailbox rename` refuses until the owner has moved the rules folder (D-07), and the Compose stack mounts the data directory read-only into the worker and setup containers.

Purpose: the owner finds rules mistakes before the worker does, never loses a mailbox's rules on a rename, and the worker can read the files in Docker.
Output: config-check and mailbox-rename changes, compose mount, and tests.
</objective>
