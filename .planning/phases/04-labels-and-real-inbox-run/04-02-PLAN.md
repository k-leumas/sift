<objective>
Build the single IMAP write gate D-28 calls for: a connection-level command allowlist inside openImap (backstop for ImapFlow's hidden writes), and `imap/label-writer.ts`, the one module that issues CREATE, SELECT, UID COPY, UID STORE and UID EXPUNGE, each with its preconditions checked first. Route the owner-run probe label test through it and make CI prove no other code path writes.

Purpose: every mailbox write in Phase 4 (and M2 relabel handling later) goes through this gate, so "Sift never deletes, sends or modifies mail" (ACT-05) is enforced by code and checked by tests rather than by discipline. It also gives the label step (04-09, 04-10) a LabelSession seam it can drive and tests can fake.
Output: connect.ts allowlist and permits, label-writer.ts, the probe on the gate, and three test files.
</objective>
