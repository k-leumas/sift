<objective>
Compose the tiers into the per-mailbox classification pass: load and version the rules, scan pending mail newest first in locked chunks, decide each message by exact rule or by the local LLM within the per-pass cap, record every decision through the single write path, stop LLM work on an outage while still writing exact-rule decisions, and keep one bad message from stopping the rest.

Purpose: this is the pipeline behaviour the phase goal names (every ingested message gets a category or is marked for review, with a replayable trace). 03-09 calls it from the worker batch and 03-12 reuses its candidate classifier for re-runs.
Output: run.ts, untrusted-email.ts, the classification test harness with the shared E8 assertion, and the pass and trace tests.
</objective>
