<objective>
Ship `sift trace <slug>`: exact lookup by message id or Message-ID, search by subject, sender and day, and a renderer that prints the README "Decision traces" tree with the real action history, the full LLM span, rule condition summaries from the snapshot and a rules-changed hint. `--all` shows every decision and the label moves between them; `--json` prints the raw rows.

Purpose: TRC-05 says the owner can retrieve the full trace of any message from the command line; the live run (04-13) samples about 20 decisions this way, and every one must be explainable from its trace (D-32).
Output: scoped trace reads in @sift/db, a pure renderer, the command, and three test files.
</objective>
