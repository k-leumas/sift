<objective>
Write the label step's decision table (Research Pattern 1) as one pure, fully tested function, planLabelStep, with the tuning constants the label step uses. It covers dry run and apply. 04-08 (dry run and paused, worker hook) and 04-09/04-10 (apply executor) only carry out the steps it returns.

Purpose: what Sift does to a message in each mode (label it, move Sift's label, remove Sift's label, hold it, skip it, give up after retries) is decided in a single place that tests cover row by row, before any code touches the mailbox. This plan was split out of 04-08 during plan revision to keep 04-08 inside the per-plan context budget. It does not depend on any other plan, so it runs in wave 1 and adds no wave to the phase.
Output: apps/worker/src/labels/plan.ts and apps/worker/test/labels-plan.test.ts.
</objective>
