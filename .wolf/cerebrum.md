## Key Learnings
- `pnpm -s lint` exits 2 under pnpm 12 even when `pnpm lint` exits 0 — check gate exit codes without -s.
- Linux uid/permission bugs hidden by Docker Desktop (macOS) can be reproduced in a throwaway `docker run --rm --user root sift:local` by chown-ing paths to 1001 and `su node` (uid 1000).
- Biome diagnostics do not show in --stdin-file-path mode; to probe an override, copy biome.json into a scratch dir with a .gitignore + git init and lint a probe file there.

- **Project:** sift
- **Description:** **Self-hosted email triage that learns from you. Rules in plain English, a tiny classifier trained on your corrections, and a small local LLM only when it's needed.**
- Shell default Node is 26.3.0, but the project needs 26.10.0 (.nvmrc). Prefix with `PATH=$HOME/.nvm/versions/node/v26.10.0/bin:$HOME/Library/pnpm:$PATH`. In agent shells `pnpm` is a lazy-nvm zsh function, so `unfunction pnpm` first. Global pnpm 12.6.0 auto-switches to the packageManager pin (12.7.0).
- The worker runs .ts from source via Node type stripping. Workspace packages export `./src/*.ts` (no dist). The CLI command table lives in apps/worker/src/command.ts, and modules under src/commands/ load lazily via a computed import URL.

- lefthook hooks are live: every commit runs `biome check` on staged js/ts/json and commitlint (config-conventional, header and body lines <=100 chars). Never use --no-verify.
- Biome 2.5: use `linter.rules.preset: "recommended"` (the boolean is deprecated); `biome check --write` rewrites folder negations to `!dir`. The ISO-04 guard is a `noRestrictedImports` override on `apps/**/src/**`; apps/*/test may import pg.
- pnpm `--save-exact` does not pin range specs (`@types/node@26` saved as `^26.6.3`). Hand-pin and re-run `pnpm install`.
- gsd-tools lives at ~/.claude/gsd-core/bin/gsd-tools.cjs. In zsh, wrap it in a function (`G() { node ... "$@"; }`), not a string variable.
- Local db: `docker compose up -d --wait db` -> container sift-db-1 (pgvector 0.8.7, PG 18.6), volume sift-pgdata, 127.0.0.1:5432. Superuser checks: `docker compose exec -T db psql -U postgres ...`. Bootstrap rerun: `psql -v ON_ERROR_STOP=1 -U postgres -f /docker-entrypoint-initdb.d/10-sift-bootstrap.sql`.
- The harness secret-read guard blocks any Bash command whose text names `.env`/`.env.development` (even `git check-ignore`, `ls | grep .env`). Generate env files via a scratchpad script that never prints values, and pass path lists to `git check-ignore --stdin`.
- zsh `echo` interprets backslash escapes (`\connect` -> `\c` truncates output). Use `printf '%s\n'` for strings with backslashes.

- drizzle-kit 0.31: `pnpm db:generate --custom --name=x` writes an empty SQL file + journal entry; plain generate diffs schema. Re-running generate with no schema change prints "No schema changes" (use it to confirm snapshots match after formatting). Custom migrations need `--> statement-breakpoint` between statements.
- DB tests: root vitest.config.ts loads .env.development; packages/db/test/global-setup.ts migrates sift_test_<run>_tpl once per run; tests call freshDatabase() for a per-file clone and seedMailboxes/seedScopedRows for data. Owner writes to scoped tables need set_config('app.mailbox_id', id, true) (FORCE RLS).
- `.env.development` is generated by scratchpad make-dev-env.sh from `.env` (never print values); process.loadEnvFile does not override vars already set, so `SIFT_TEST_ADMIN_URL= pnpm vitest ...` simulates no-DB.
- Zod 4.6: per-schema `error` beats per-parse `safeParse(data, { error })`; return undefined from a schema error fn to fall through. Object/array refinements are skipped after invalid_type in children unless `superRefine(fn, { when: () => true })`. `z.httpUrl()` rejects localhost; use `z.url({ protocol: /^https?$/ })`.
- yaml 2.9: `maxAliasCount` is a `toJS()` option, not parseDocument. Default prettyErrors appends source text to messages; use `prettyErrors: false` when values may be secret.
- @sift/core/config: config check, config apply and worker share loadConfig -> applyEnvOverrides -> (checkMailboxEnv unless schema-only). Logging: createLogger + redactText from @sift/core/log.
- Vitest 5 junit reporter writes .vitest/junit/output.xml in the repo by default; pass `--outputFile.junit=<scratch>` for RED evidence. gsd check tdd-red-evidence matches Vitest junit at class level (target = test file path).
- Catalog schema check: packages/db/test/support/catalog.ts collectCatalogViolations(adminClient) must return [] on a migrated DB. A new table needs mailbox_id NOT NULL + single-col FK to mailbox, ENABLE+FORCE RLS, exactly one standard policy, UNIQUE (mailbox_id, id), mailbox_id-paired child FKs, explicit grants and a set_updated_at trigger, or a CATALOG_ALLOWLIST entry with a reason. Adding a mailbox column means updating MAILBOX_COLUMNS.
- has_table_privilege raises on an unknown role; pg_get_userbyid(0) is not 'public' (map polroles oid 0 manually). STANDARD_POLICY_EXPR is the pg_get_expr-normalized text, not the source text.
- CI can be replayed locally without touching sift-db-1: run pgvector/pgvector:0.8.7-pg18-trixie on 127.0.0.1:55432, docker exec the bootstrap with CI password vars exported, then `pnpm test` with SIFT_TEST_ADMIN_URL pointing at :55432 (exported vars beat .env.development). actionlint is at /usr/local/bin/actionlint.

- [2026-10-03] Agent Bash runs zsh: `FILES="a b"; git add $FILES` does NOT word-split. Use an array `FILES=(a b); git add "${FILES[@]}"`.
- [2026-10-03] The git index holds the user's pre-staged .wolf/.claude files. Always commit with an explicit pathspec (`git commit -- <files>`) so they are not swept in.
- [2026-10-04] Negative greps in acceptance criteria scan comments too: never write the forbidden literal (e.g. 0.0.0.0) in a comment of the checked file.
- [2026-10-04] Repeated in 01-03 with `pgEnum` in a scoped.ts comment. Before writing comments, scan the plan's acceptance greps for forbidden literals.
- [2026-10-04] Do not run `state.advance-plan` in a command whose output is truncated and then re-run it: it advanced twice (01-04). Run once and read the JSON.
- [2026-10-04] Never use `gsd query commit` while the user has staged files: commit with `git commit -- <pathspec>` so the pre-staged .wolf/.claude files stay out.
- [2026-10-04] In registry/rename tests, derive IMAP usernames independently of the slug, or a rename shows up as an imap_username update.
- [2026-10-04] `cp` is aliased to `cp -i` in agent zsh: restoring a file with `cp` silently does nothing ("not overwritten"). Use `command cp -f`.
- [2026-10-04] A net.Server test socket with no 'data' listener never sees the peer's FIN, so 'close' never fires; call socket.resume().
