2. Moving an A row to B under A (`update <table> set mailbox_id = $B where id = <A row>`) fails with 42501 on every non-append-only table. For mailbox_status, filter by mailbox_id = A.

5. A non-UUID setting: `set_config('app.mailbox_id', 'not-a-uuid', true)` followed by `select * from message` fails with 22P02.
6. Upper-case UUID: inScope(A.toUpperCase()) reads exactly A's message ids (ISO-01 encoding edge).
7. Empty mailbox C: inScope(C) reads 0 rows from every scoped table, and no B or A rows (ISO-03 empty edge).
8. Unfiltered update: `update message set updated_at = now()` under A changes exactly A's message rows (rowCount equals A's seeded count). The admin snapshot shows B's message updated_at unchanged.
9. Append-only: under A, `update decision set updated_at = now()` and `delete from label_event` fail with 42501, raised by the privilege check before any policy (D-40).
10. ISO-01 empty edge at runtime: under A, `insert into message (mailbox_id) values (null)` fails with 42501 (the RLS WITH CHECK evaluates NULL), and through the admin URL the same insert fails with 23502 (NOT NULL).
