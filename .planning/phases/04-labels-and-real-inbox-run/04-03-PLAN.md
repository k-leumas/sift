<objective>
Give the worker a way to reach Ollama that does not need open internet access: a small `sift egress-relay` command (the sift image, node:net only) that forwards TCP to models.url's host and port and nothing else, plus an opt-in transport rewrite (SIFT_MODELS_RELAY_HOST) in the worker and sift classify. Add the static checks D-29 asks for: no telemetry or mail-sending dependency, and no network call site outside a pinned allowlist.

Purpose: plan 04-06 puts the worker on an internal-only Compose network; this relay is then its only route off the stack, so "nothing leaves the machine except calls to the configured model URL" (SEC-02) holds by construction. The static tests keep later code from adding another route.
Output: the relay command, the transport rewrite, and three test files plus a dependency-test extension.
</objective>
