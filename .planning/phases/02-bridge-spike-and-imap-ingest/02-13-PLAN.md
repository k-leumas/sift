<objective>
Wire ingest into the running worker. Every supervisor tick runs, per due mailbox:
1. take the ingest lock (D-03)
2. check the mailbox is active and not held
3. open the IMAP connection with the mailbox's configured TLS mode and pin (D-40, D-42, D-73, D-74)
4. run the sync engine against a database-backed store with the mailbox's ingest settings (D-26, D-75)
5. record the outcome, including backfill progress, as owner-visible mailbox status (D-26, D-33, D-34, D-75)

Prove the phase's ingest success criteria end to end against a real IMAP server and the real database.

Purpose: this is where ROADMAP success criteria 3, 4 and 5 become true. Everything earlier in the phase is a component; this plan is the product.
