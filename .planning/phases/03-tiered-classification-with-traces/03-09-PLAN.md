<objective>
Run classification in the worker: after each successful ingest, the per-mailbox batch runs the 03-08 pass, then records one status that tells the owner what is wrong (rules file, Ollama) without slowing ingest for a rules problem and with backoff for an outage. Wire the runtime into `sift worker` with one process-wide single-flight gate.

Purpose: success criteria 1-5 happen in the running worker, on the owner's schedule, with failures visible in `sift mailbox list` and isolated per mailbox.
Output: mailbox-batch.ts and worker.ts wiring, a status option, and batch-level and spawned-worker tests.
</objective>
