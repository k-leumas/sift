1. `backup.ts`:
   - `backupFileName` uses the UTC compact timestamp.
   - `ensureWritableDir`: `mkdir -p`, then write and remove `.sift-write-probe`. On EACCES or EPERM, throw `backup directory <dir> is not writable; on Linux run: chown 1000 <dir>`.
   - `writeBackup`:
     - Parse `target.url` with `URL`. Take the password out into `PGPASSWORD` and build a `--dbname=` URL without it.
     - `spawn(target.pgDump ?? 'pg_dump', ['--format=custom', '--no-password', '--dbname=<url without password>'], { env: { ...process.env, PGPASSWORD } })`. No shell.
     - Pipe stdout into `createWriteStream(path, { flags: 'wx', mode: 0o600 })`.
     - On a non-zero exit or spawn error, delete the partial file and throw BackupFailedError. Its stderr text goes through `redactText` with the password (`@sift/core/log`).
   - `pruneBackups` sorts matching names descending (the timestamp format sorts chronologically) and removes everything after the first `keep`.
2. `migrate.ts`. Order inside the advisory lock:
   1. Pending detection: journal entries (`readMigrationFiles`) beyond the count recorded in `drizzle.__drizzle_migrations`, or all of them when `to_regclass` is null.
   2. If anything is pending:
      - `backup === undefined`: throw BackupRequiredError.
      - `backup` is a target: `ensureWritableDir`, then `writeBackup(backup, backupFileName(new Date(), lastPendingTag))`, then `pruneBackups(dir, BACKUP_KEEP)`.
      - `backup === false`: skip.
   3. `ensureAppRole`.
   4. The drizzle migrator.

   A failed backup therefore changes nothing: no role rotation and no migration. Return `{ applied, backupFile }`.
3. `global-setup.ts`: pass `backup: false`. Throwaway test templates need no dump.
4. `apps/worker/src/commands/migrate.ts`: read the CLI env from the interfaces block. Use `requireDatabaseUrl(io.env, 'SIFT_OWNER_DATABASE_URL')` and treat a blank SIFT_DB_APP_PASSWORD as missing.
   - Build `backup` from SIFT_BACKUP_DATABASE_URL when set (dir = resolve(io.cwd, SIFT_BACKUP_DIR ?? 'backups'), pgDump = SIFT_PG_DUMP); otherwise `undefined`.
   - Print `No pending migrations.`, or `Backup written: <relative path>` followed by `Applied <n> migrations: <tags comma-separated>`. Return 0.
   - On error, print `sift migrate: <message>` to stderr and return 1. Never print a URL or password.
5. `scripts/pg-dump-via-compose.sh` (POSIX sh, executable):
   - `cd` to the repo root (the script's parent directory).
   - Rewrite the host:port of the `--dbname=` argument to `127.0.0.1:5432`, which is the server's own address inside the db container. Pass all other args unchanged.
   - `exec docker compose exec -T -e PGPASSWORD db pg_dump <args>`. The dump streams to stdout, so writeBackup works unchanged. This is how a Mac host without pg_dump 18 backs up (D-29 host-dev note).
