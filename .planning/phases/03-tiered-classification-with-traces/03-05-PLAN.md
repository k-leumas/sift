## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| email fields (untrusted) -> prompt | Sender-controlled text enters the user message |
| owner rules snapshot (trusted) -> system message | Owner text is the only content of the trusted part |
| model output (untrusted) -> code | The model's answer may be anything, including an echo of the email |
