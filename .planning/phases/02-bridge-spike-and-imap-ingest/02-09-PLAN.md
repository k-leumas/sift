<objective>
Implement the `FolderSource` contract (02-07) over ImapFlow:
- EXAMINE the configured folder
- list and date UIDs
- fetch the selected headers with envelope and body structure
- download one decoded text part with a byte cap

Prove the adapter against a real STARTTLS IMAP server, including that it never changes a flag (D-11).

Purpose: this is the only code that turns IMAP into ingest records. Getting PEEK/EXAMINE, the `n:*` boundary and bigint handling right here protects every later cycle.

Output: `apps/worker/src/imap/folder-source.ts`, synthetic mail fixtures and the Dovecot tests.
</objective>

  export function toUidSet(uids: readonly number[]): string;   // sorted, deduplicated, compressed ranges, e.g. [1,2,3,7,9,10] -> "1:3,7,9:10"; throws on an empty list
  export function createFolderSource(client: ImapFlow): FolderSource;
    examine(folder)            -> client.mailboxOpen(folder, { readOnly: true }); returns { uidValidity: Number(m.uidValidity), uidNext: m.uidNext, exists: m.exists }
    fetchDates(range)          -> client.fetchAll(range, { uid: true, internalDate: true }, { uid: true })
    fetchHeaders(uids)         -> client.fetchAll(toUidSet(uids), { uid: true, internalDate: true, size: true, envelope: true, bodyStructure: true, headers: [...HEADER_FIELDS] }, { uid: true })
    listUids(range)            -> client.search({ uid: range }, { uid: true }) ([] when the server returns false)
    searchSince(since)         -> client.search({ since }, { uid: true })
    downloadText(uid, part, n) -> client.download(String(uid), part, { uid: true, maxBytes: n }); read the stream into a string; truncated when the byte count reached n
  Every method except examine throws if no folder is open, or the open folder is not the one examined.
